# Salamz

**Bringing neighbours closer.**

Salamz is a neighbourhood community app designed to help people connect with nearby residents, share useful information, offer help, and build stronger local communities.

## Getting started

Install dependencies:

```bash
pnpm install
```

Start the Expo development server:

```bash
pnpm start
```

Use the Expo Go app or a development build to run Salamz on a device.

## Project status

Salamz is under active development. Features and interfaces may change.
